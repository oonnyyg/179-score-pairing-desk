# pairdesk — 本地积分编排赛事管理器

一个用 Go 标准库实现的命令行工具：根据已完成比赛生成下一轮对阵，
并让配对依据（配对目标值）和排名变化可追溯。

> **注意**：本工具实现的是一套**自定义积分编排规则**，用于本地赛事管理，
> 并不宣称完整实现任何官方瑞士制（Swiss-system）规程。

## 运行

```sh
go run ./cmd/pairdesk -dir <状态目录>
```

程序从标准输入按行读取 JSON 操作（JSONL），每个操作在标准输出返回一行
JSON 响应。状态保存在 `-dir` 指定目录下的 `state.json`（默认
`pairdesk-data`），正常重开后结果与排名保持一致。

## 操作

- `{"op":"init","players":[1,2,3,4,5]}` — 初始化赛事。最多 16 名选手，
  编号为正整数且唯一。已有状态时拒绝重复初始化。
- `{"op":"pair"}` — 生成下一轮对阵。当前轮结果未全部提交前拒绝生成。
- `{"op":"result","results":[{"a":2,"b":3,"outcome":"a_win"},...]}` —
  整批提交当前轮结果。`outcome` 取 `a_win` / `draw` / `b_win`。
  整批校验通过后才应用：缺少对局、对局不属于本轮、结果非法或重复提交
  已确认轮次都会整体拒绝，不会部分记分。
- `{"op":"withdraw","player":3}` — 轮间退出（当前轮有待提交结果时拒绝）。
  退出者历史成绩保留并仍参与排名，但不再进入后续配对。
- `{"op":"standings"}` — 当前排名。
- `{"op":"history"}` — 历轮对阵、结果与每轮配对目标值。

## 规则

- 记分：胜 2 分，平 1 分，负 0 分。每轮每人最多一场，两人不能重复交手。
  不处理棋子走法与先后手。
- 轮空：奇数人数时，从**从未轮空过**的选手中按积分升序、再按编号升序
  固定选一人轮空，记 2 分（所有人都轮空过时则在全体中按同样规则选择）。
- 配对：为其余选手在**所有**完整配对方案中搜索，使各对积分差绝对值之和
  （配对目标值 `objective`）最小，而非逐人贪心。并列时先将每对按编号
  升序、整组对按字典序排列，选择字典序最小的整组方案。无解（无法避免
  重复交手）时明确失败，且不改换已选定的轮空者。
- 排名：总分降序 → 实际对手当前积分总和（Buchholz）降序 → 编号升序。
  轮空不虚构对手。

## 测试

```sh
go test ./...
```

覆盖：非贪心全局最优配对与字典序并列裁决、轮空选择与轮换、无解失败
不改变状态、结果整批校验拒绝后状态不变、已确认轮次拒绝重复提交、
轮间退出保留历史、保存/重开后排名与配对一致。
