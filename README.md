# pairdesk — 本地积分编排赛事管理器

一个基于**自定义积分编排规则**的单机赛事管理器。它**不是**、也不宣称完整实现任何官方瑞士制（Swiss-system）规程；配对、轮空与破同分规则均为本项目自定义。

## 运行

仅需 Go 标准库：

```sh
go run ./cmd/pairdesk
```

程序从 stdin 按行读取 JSONL 操作，每行输出一个 JSON 响应到 stdout。所有状态保存在请求中 `dir` 指定目录下的 `tournament.json`，重开进程后结果一致。

## 操作

| op | 字段 | 说明 |
| --- | --- | --- |
| `init` | `dir`, `players` | 新建赛事，选手为正整数编号，最多 16 人 |
| `pair` | `dir` | 生成下一轮对阵（当前轮结果未全部提交前报错） |
| `submit` | `dir`, `results` | 整批提交当前轮结果 |
| `standings` | `dir` | 查询排名 |
| `rounds` | `dir` | 查询历轮对阵与配对目标值 |
| `withdraw` | `dir`, `player` | 选手轮间退出，历史成绩保留，不再参与配对 |

结果条目：`{"pair":{"a":1,"b":2},"winner":1}`，`winner` 为胜者编号，`0` 表示平局。

示例：

```jsonl
{"op":"init","dir":"./data","players":[1,2,3,4,5]}
{"op":"pair","dir":"./data"}
{"op":"submit","dir":"./data","results":[{"pair":{"a":2,"b":3},"winner":2},{"pair":{"a":4,"b":5},"winner":0}]}
{"op":"standings","dir":"./data"}
```

## 自定义规则

- **记分**：胜 2 分，平 1 分，负 0 分。不处理棋子走法与先后手。
- **每轮**：每人最多一场；任意两人不重复交手。
- **轮空**：奇数人数时，从**从未轮空过**的活跃选手中，按积分升序、再按编号升序固定选一人轮空，记 2 分（若所有人都轮空过，则在全体活跃选手中按同样规则选择）。轮空不虚构对手。
- **配对**：对轮空外的选手穷举所有完整配对，取**总积分差绝对值之和最小**者（目标值即 `rounds` 输出中的 `objective`），不是逐人贪心。并列时先把每对编号升序、所有对按字典序排列，取整组字典序最小者。无解时明确失败，且已选轮空者不更换、不产生新轮次。
- **结果提交**：整批校验（每盘恰好一条结果、胜负合法）后才应用；缺少对局或结果非法时不部分记分；已确认轮次不能重复提交。
- **排名**：总分降序 → 实际对手当前积分总和降序（轮空不算对手）→ 编号升序。退出者保留历史成绩并继续参与排名展示。

## 测试

```sh
go test ./...
```

覆盖非贪心配对（贪心首选会导致死路的局面）、目标值最小化、轮空选择与不重复、整批拒绝后的状态不变、重复提交拒绝、退出后不再配对、保存/重载一致性等。
